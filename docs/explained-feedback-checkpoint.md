# Пояснения ошибок и тихие подсказки — 07.10.2026

- [x] Общий web/Android UI: удалены сообщения «Текст сравнен… подсказок не найдено» и «Текст исправлен вручную…». При analyzed без предложений секция полностью отсутствует. При ручной правке предложения по-прежнему заблокированы; исходная расшифровка и отметка принятой помощи сохранены. Сообщение реального сбоя assistance не скрыто.
- [x] Prompt `answer_analyzer_v2.md`: для всех настоящих ошибок требуются причины, связь с заданием, разница значения/контекста/сочетаемости, грамматическое правило или влияние порядка слов. Отличие от канона само по себе не ошибка; допустимая естественная альтернатива не требует исправления/снижения оценки. Произношение по одному тексту не выдумывается.
- [x] Новые AI-ответы валидируются `ExplainedAnswerAnalysis`: у каждой ошибки обязательный непустой `explanation_ru`, до 800 символов. В обычном API/storage поле опционально, чтобы старые сохранённые разборы оставались читаемыми без повторного AI-вызова и миграции БД.
- [x] Каждое пояснение показывается текстом под evidence → correction. Оно сохраняется при canonical alignment и замене неподтверждённого свободного текста для близкой пословной коррекции. Общая палитра/шрифт web и Android соблюдены.
- [x] Проверки: backend analyzer/adapter 33 tests; полный backend/scripts pytest прошёл, 8 штатных внешних проверок skipped; attempts API 7 tests включая сохранение explanation_ru в DB JSON; App/Assistance UI 89 tests включая web и Android-layout, полный frontend 158 tests; lint/typecheck/production build и diff check прошли. AI не вызывался: адаптер проверялся mock Responses API, timeout/retry/env-модель и scoring не менялись.

- [x] По явной команде и отдельному согласованию включено в Android 1.24/code34; APK собран, проверен и опубликован. [Доказательства](android-1.24-release.md).
