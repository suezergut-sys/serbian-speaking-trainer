Владелец отдельно согласовал 1.20 / versionCode 30 в этом чате. Релиз подготовлен от актуального main `ebcac2f273dd307c75f2155731c135e17778c905` (1.19), в изолированной рабочей копии; старый checkout и его незакоммиченные backend/Android изменения не включены.

## Состав

- Читаемая тёмная кнопка ручного ввода при ошибке STT; в AGENTS добавлено обязательное соблюдение палитры и общего шрифта во всех новых UI-элементах и состояниях.
- Статистика начинается с выбора недели; без заголовка/подписи и activity/phrases selector. Три карточки рядом: «Дней», «Повторений», «Выучено». Повторения — число проверенных переводов за неделю, выучено — mastered_phrase_count за выбранную неделю. Список фраз сохранён ниже графика.
- Профиль и выход перенесены в существующие настройки с выбором алфавита. UI настройки backend удалён, production API сохраняется в конфигурации.
- После transcript — зелёная круглая галочка проверки слева и круглый микрофон с неподвижными стрелками справа. Сохраняются блокировка действий во время проверки/STT и существующие защиты от поздних ответов, смены упражнений и двойного submit.
- [Мягкая помощь](transcription-assistance-design.md) только спроектирована. Backend/STT prompt/scoring не менялись; реализация требует личного ревью владельца.
