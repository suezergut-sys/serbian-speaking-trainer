# 17.10.2026 — обратная связь и уведомления об активности

## Реализация

- [x] При смене темы web-индикатор подготовки занимает центр всей панели практики.
- [x] У каждой фразы повторения API возвращает исходные `topic_id` и `topic_title_ru`; desktop, мобильный web и общий Android-интерфейс показывают «Фразы для повторения / Банк», с переводом для English. У собственных фраз без связанной темы косая черта не добавляется. Названия собственных тем не переводятся автоматически.
- [x] В настройках RU/EN добавлен раздел «Оставить обратную связь». Текст можно написать или надиктовать, исправить и отправить вручную. Запись ограничена 60 секундами, загрузка — существующим лимитом аудио; текст — 5000 символами. При ошибке черновик остаётся в форме. Закрытие/уход/сворачивание освобождают микрофон и отменяют расшифровку.
- [x] Авторизованный `POST /api/feedback` сохраняет текст в отдельную таблицу `user_feedback`: UUID, FK пользователя, UTC-дата/время, содержание. Автор определяется по сессии; подстановка чужого user_id запрещена схемой. Удаление пользователя каскадно удаляет отзывы.
- [x] Авторизованный `POST /api/feedback/transcribe` использует настроенную backend-модель распознавания без сербского prompt/language. Ответ валидируется Pydantic. Аудио существует только в памяти, не попадает в БД, диагностику, логи или fixtures. Тесты используют синтетические байты и mock OpenAI.
- [x] Telegram получает email аккаунта и одно из сообщений: «зарегистрировался в SerboTalk», «оставил обратную связь в SerboTalk», «выполнил 20 проверок за день в SerboTalk». Последний триггер уточнён владельцем: достижение 20, а не выбор настройки. Содержание отзыва и аудио не отправляются.
- [x] Отправка выполняется после commit; rollback отбрасывает уведомление. Повтор авторизации и повтор сохранённой попытки с тем же request ID не дублируют событие. Сетевой timeout по умолчанию 3 секунды; ошибка Telegram не отменяет сохранённый отзыв/ответ. Доставка best-effort, без повторов и постоянной очереди: при сбое сети/процесса уведомление может быть потеряно. Повторы после неоднозначного timeout намеренно исключены из-за риска дублей.
- [x] `TELEGRAM_BOT_TOKEN` (SecretStr), `TELEGRAM_CHAT_ID`, `TELEGRAM_TIMEOUT_SECONDS` — только backend-env. Локальный игнорируемый `.env` настроен; реальное тестовое сообщение успешно доставлено указанному владельцем получателю. Токен не включён в исходники и документацию.
- [x] Alembic `713ce912ab30` добавляет таблицу; downgrade удаляет только таблицу обратной связи. Проверены повторный upgrade и roundtrip; локальная SQLite обновлена до head.
- [x] Политика конфиденциальности обновлена RU/EN с описанием обратной связи и уведомлений Telegram.
