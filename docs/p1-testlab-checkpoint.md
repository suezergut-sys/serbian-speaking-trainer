# Начало P1 и тестовый контур — 30.09.2026

P1 начат по прямому поручению владельца; ручная приёмка P0 и завершение всего P1 остаются открытыми. Работы выполняются в управляемом worktree `audit-p0`, ветка `codex/p1-test-harness`; несвязанные изменения основного checkout сохранены.

## Реализовано

- Изолированный web/Android testlab: локальный Supabase-совместимый провайдер подписанных сессий, отдельная SQLite, synthetic recorder и fake AI/STT. Google-учётная запись владельца не требуется. Production backend сохраняет обычную проверку авторизации.
- Android `lab` с отдельным application ID и assets; production `prod` защищён от включения тестового входа и mixed-content конфигурации. Секреты, данные и отчёты исключены из Git.
- Полный сквозной цикл: вход → тема → фраза → синтетическая запись → STT → ручная правка → оценка → следующая видимая фраза. В Android применяются настоящие касания по наблюдаемым границам WebView; DOM-события отправки не подменяются.
- Число SQL и SDK-вызовов, их длительности в `Server-Timing`; опциональные метрики UI. Разные платформы не объединяются в одну сводку.
- Начало P1.3: новая сессия использует известное число попыток 0, устраняя лишний COUNT; чтение существующей сессии сохраняет фактический подсчёт.
- Исправлен подтверждённый дефект: после длинного разбора новая фраза могла оказаться выше экрана. При показе нового упражнения приложение возвращает фразу в видимую область.

Запуск и ограничения: [testlab.md](testlab.md). Статусы всех оставшихся задач: [audit-roadmap.md](audit-roadmap.md).

## Публикация и ручная приёмка

- Production web: https://serbian-speaking-trainer.vercel.app
- Production API: https://serbian-speaking-trainer-api.vercel.app
- Публикация текущих изменений и окончательная проверка deployment выполняются после финального gate.
- Личный Chrome через плагин недоступен из-за ошибки request-header policy/тайм-аута; отдельный тестовый Chrome работает. Продуктивную Google-сессию не копировали в runner.
- Эмулятор запускается headless для автоматизации. Уменьшение видимого окна предусмотрено скриптом, визуальная проверка размера окна владельцем ещё не подтверждена.
- Настоящий Google-вход, запись голоса, качество STT/AI, permissions/background/resume и скорость физического телефона остаются отдельными проверками.

Ручной сценарий: обновить обычный APK, проверить сохранение учётной записи и алфавита, исправить расшифровку смешанной раскладкой, получить результат, прокрутить длинный разбор и нажать «Следующая». Новая фраза должна появиться в видимой области; навыковые бары не возвращаются.
