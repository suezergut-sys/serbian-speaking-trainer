## Операторский порядок удаления

До обработки первого запроса подготовить проверяемую процедуру: подтвердить владение email, идентифицировать Supabase и application user ID, отозвать сессии Auth и учесть срок жизни уже выданных JWT, удалить Auth-пользователя поддерживаемым административным методом, затем удалить application user с каскадом пользовательских записей. Не удалять только application user при ещё действующем токене: синхронизация способна создать его заново. Проверить отсутствие учебных и диагностических данных и ответить владельцу. Реальных пользователей в этой задаче не удаляли. Retention резервных копий требует отдельной проверки; точные сроки пока не обещаны.

Официальные требования: [удаление аккаунта](https://support.google.com/googleplay/android-developer/answer/13327111), [Data Safety](https://support.google.com/googleplay/android-developer/answer/10787469). Реализацию, публикацию, Android и ручную приёмку учитывать раздельно.
