# Единый стандарт Ekavica — 26.10.2026

По запросу владельца весь учебный материал использует сербскую экавицу: общий
каталог, личные фразы, генерация, варианты переводов, подсказки и проверка,
независимо от языка интерфейса RU/EN и алфавита.

## Реализация

- [x] Правило закреплено в AGENTS.md и едином версионируемом системном дополнении
  `serbian_ekavica_v1.md`. Оно добавляется ко всем structured AI operations после
  инструкций языка обратной связи; пользовательские строки остаются данными.
- [x] Pydantic-валидированный результат дополнительно проверяется сервисом
  `serbian_standard`: известные иекавские слова в переводах, подсказках, словаре,
  corrected_sr, corrections и accepted_alternatives отклоняются безопасной ошибкой.
  Это дополнительный ограниченный словарь защиты, а не полный морфологический
  анализатор. Общее языковое правило применяется моделью ко всей лексике.
- [x] Проверка не выдаёт автоматические 100% по известному иекавскому варианту.
  Загрязнённый старый канон/вариант исключается из эталонов, чтобы после анализа
  он не подменил правильное экавское исправление. Неподтверждённый моделью ответ
  повторно проверяется не более одного раза, затем возвращается безопасная ошибка.
- [x] Иекавица объясняется как несоответствие выбранному стандарту курса,
  а не как неправильный сербский вообще. Оба варианта являются стандартными:
  [решение Одбора за стандардизацију српског језика](https://www.ossj.rs/odluke-i-saopstenja/u-republici-srbiji-u-sluzbenoj-upotrebi-je-srpski-jezik-ekavskog-i-ijekavskog-izgovora/).
- [x] Нет механической замены `je`/`ije`: `nije`, `pijem`, `prijatelj`, `dvoje`,
  `bolje` остаются допустимыми. Исходные transcript/raw_text/evidence не меняются;
  STT остаётся дословным. По тексту не выносится диагноз произношения.
- [x] API/UI-контракт и тексты интерфейса не менялись. Новые объяснения модели
  используют существующий feedback_language ru/en; проверено в обоих контекстах.
