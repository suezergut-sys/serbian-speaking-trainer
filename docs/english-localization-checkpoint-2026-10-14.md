# Английская локализация — 14.10.2026

## Реализовано локально

- [x] Первый пункт настроек: «Язык интерфейса и исходных фраз» / “Interface and source language”, варианты `Русский` / `English`.
- [x] Выбор применяется сразу и хранится на устройстве; закрытый localStorage допускает выбор до конца текущей сессии. Русский — по умолчанию. Сербский алфавит остаётся независимой настройкой.
- [x] Навигация, desktop/mobile страницы, настройки, ошибки, статистика, административные подписи, вход и публичные legal-страницы поддерживают английский. Даты используют выбранную локаль.
- [x] Отдельная база данных приложения `frontend/src/locales/phrases.en.json`: 160 английских исходных фраз для всех восьми тем, исходные ID и те же канонические сербские переводы. Подготовка готовой фразы не вызывает AI.
- [x] Английские контекстные подсказки связаны с прежними словами. API получает тот же ключ; открытие подсказки после смены языка не создаёт второго штрафа. Сербские слова и исправления сохраняются без перевода интерфейса.
- [x] Смена языка не сбрасывает активную фразу, черновик, сессию или прогресс. Повторение и статистика используют те же записи БД.
- [x] Новый клиент передаёт `X-Interface-Language`; backend изолирует язык на время запроса. Отсутствие заголовка сохраняет русский для прежних клиентов независимо от browser `Accept-Language`.
- [x] Новые объяснения оценки создаются на выбранном языке. Английская инструкция и подготовка собственных русских/английских фраз хранятся в версионированных prompts. Pydantic-валидация, AI timeout/retry и безопасность ключа сохранены.

Персональная БД, schema и Android metadata не менялись: английский каталог представляет дополнительный слой отображения поверх прежних канонических фраз. Собственные темы и фразы, а также уже полученные произвольные объяснения сохраняют исходный язык. Предпочтение языка хранится на устройстве и не синхронизируется через профиль. При подготовке английского слова, не имеющего точной контекстной привязки в готовом каталоге, оно отображается обычным текстом.
