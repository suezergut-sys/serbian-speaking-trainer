# Набор для следующего Android-релиза

Текущая выпущенная Android-версия: `1.4`.

Этот список накапливает web-изменения, которые нужно включить и отдельно проверить при следующем Android-релизе. Не менять Android-версию и не собирать APK, пока владелец не даст явную команду.

## Ожидают Android-релиза

- [ ] Скрыть панель ручной настройки backend и подсказку про эмулятор от обычных пользователей; оставить доступ только администратору.
- [ ] Проверить на Android время появления первой фразы после пакетной загрузки навыков в backend. Серверное ускорение не требует пересборки APK.
- [ ] Перенести в Android web bundle запуск тренировки одним `POST /api/sessions/start` и проверить обычную тему и карусель повторения. До следующего APK прежние endpoints остаются доступными.
- [ ] Перенести в Android web bundle мгновенный показ пословных переводов из ответа упражнения и фоновую запись слова в неизученные. До следующего APK прежний endpoint подсказок остаётся доступным.

## Чек-лист будущего релиза

- Синхронизировать накопленный web bundle с Capacitor.
- Проверить каждый пункт на Android и отметить его выполненным.
- Повысить Android-версию на `0.1`, не переходя на `2.x` без явной команды.
- Собрать APK с именем `SerboTalk-andorid16-<версия>.apk` и выполнить mobile smoke-test.
