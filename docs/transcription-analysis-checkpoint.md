Проверки не вызывали OpenAI. Mock SDK проверяет заданную env-модель, Pydantic schema, payload без аудио, timeout/retry и safe errors. API-тесты подтверждают вызов при каждом enabled STT, отсутствие вызова при disabled, fallback на невалидном анализе, ownership и защиту mastery для более трёх принятых предложений. Unit-тесты включают новые слова без словаря, повторные слова, emoji, недопустимую подмену отрицания/чисел, низкую близость, реальную смысловую ошибку по классификации mock, точный и альтернативный допустимый ответ.

Автотесты доказывают границы обработки, но не полноту/точность гипотез реальной модели. Качество аудио не измеряется; сравнение выполняется по тексту. Дополнительный AI-вызов добавляет время и расход API. Предупреждение build о главном chunk >500 kB остаётся, сборка успешна. Схемы БД не менялись; дополнительные данные помещаются в существующие JSON receipts. Исторические проверки `local-v2`: [checkpoint ошибок](transcription-errors-checkpoint.md).
