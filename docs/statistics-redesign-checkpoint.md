# Статистика: календарь и фразы по темам — 07.10.2026

Общий React-интерфейс web/Android показывает дату сверху календарной ячейки и крупное число попыток в центре. Легенда использует попытки для обоих порогов. Цветные сегменты графика используют одинаковую ширину и выравнивание.

Ни список фраз, ни темы для него не запрашиваются на главном экране статистики. Кнопка ниже графиков открывает отдельную страницу с селектором тем, попытками, статусами и следующими повторами. Пагинация 10/50 применяется внутри выбранной темы; фразы без темы доступны как «Свои фразы». Назад на экране/аппаратный Android Back возвращает в статистику.

API: GET /api/statistics/phrase-topics, GET /api/statistics/phrases?topic_id=...; unassigned — фразы без темы. Старый запрос без topic_id сохраняет поведение. Список/подсчёт/темы изолированы по пользователю, чужие topic titles не раскрываются. Для этой правки новая миграция не нужна; предыдущая миграция синхронизации подсказок остаётся в наборе изменений.
