# Синхронизация мягких подсказок — 07.10.2026

Локально реализовано сохранение выбора в профиле пользователя. Общий React-клиент web/Android загружает значение при входе, возвращении в приложение и каждые 15 секунд на видимой странице. Запись подтверждается сервером, ошибка не меняет галочку. Настройка используется следующей расшифровкой.

API: GET/PATCH /api/auth/me/preferences, boolean assistance_enabled; авторизация обязательна, чужой user_id и посторонние поля запрещены. GET /api/auth/me включает настройку. Миграция f42b8c012d33 добавляет NOT NULL boolean default false; downgrade сохраняет связанные тренировки. Старые локальные значения не импортируются; после обновления выбор нужно сделать один раз. При одновременных изменениях действует последнее сохранение.
