# План реализации аудита

## База и границы

Работа начата 2026-09-29. Первичный аудит исследовал локальную ветку с Android 1.10.
Перед реализацией обнаружен более новый production main: `849b8a6`, Android 1.12.
Реализация ведётся от этого main в отдельном worktree. Исходные незакоммиченные
изменения в пользовательской папке не переносятся поверх production и не удаляются.

Уже реализованы: объединённый старт с первой фразой, подсказки в payload,
отложенная статистика Android, prefetch следующей фразы, проверка ES256 JWT,
повторное использование соединений, диагностика запросов и ограничение записи
активности пользователя. Эти части проверяются на регрессии, а не переписываются.
Сохраняются голосовой сценарий и выбор латиницы/кириллицы. Текущее правило
освоения — три самостоятельных результата от 95%, как в выпущенном коде.

## Команда

| Роль | Модель | Задача |
| --- | --- | --- |
| Оркестратор | GPT-6.1 Sol / medium | Контракты, интеграция, выпуск |
| Backend | GPT-6 Sol / high | API, данные, бизнес-логика и тесты |
| Frontend | GPT-6 Sol / high | Общий учебный интерфейс и тесты |
| QA | GPT-6 Luna / medium | Исходные и итоговые проверки |
| Документация | GPT-6 Luna / medium | Проверенные изменения и ручная приёмка |
| Reviewer | GPT-6.1 Sol / medium | Независимая проверка сложных изменений |

Модели назначены для разработки проекта и не определяют OpenAI-модели приложения.
Настройки проекта используют [официальный формат агентов](https://learn.chatgpt.com/docs/agent-configuration/subagents).
Текущие вызовы делегирования явно задают модель; автоматическую перезагрузку
новых файлов настроек в уже открытом чате не предполагаем.

## Проверки и контрольные точки

Автоматические тесты используют mock AI, не расходуют API-бюджет и не хранят аудио.
Quality gate: backend pytest, frontend component tests, lint, typecheck/build.
Отдельно проверяются миграции upgrade/downgrade, изоляция пользователей,
повтор запроса, потеря ответа, лимит и отказ AI. Для PostgreSQL-конкуренции
SQLite-тесты не объявляются достаточным доказательством.

Релиз фиксирует точный SHA, ссылки deployment, Ready, smoke-check и APK.
Человеческая проверка входит в контрольную точку; автоматический smoke-test
её не заменяет. Владелец согласовал Android 1.13 (versionCode 23) 2026-09-30; APK и ручная приёмка фиксируются отдельно.

## Доработка P0 по ручной проверке — оценка после STT

- Исправлена общая нормализация сербской кириллицы и Unicode NFC; неизвестные буквы не удаляются при сравнении. Канонический ответ учитывается даже при неполном списке допустимых вариантов.
- Введена проверка обоснованности issues, один ограниченный повтор противоречивого анализа и отказ от сохранения ложной оценки. Пояснения ответов с близкими заменами слов строятся из проверенных пар evidence/correction.
- Клиент учитывает смену алфавита во время STT и не подсвечивает различия только в Unicode/алфавите. Изменения клиента включены в Android backlog.
- Ручная авторизованная проверка остаётся открытой: браузерный инструмент возвращает `Unable to load browser request-header policy`. Новая Android-сборка этой доработкой не выполняется; P1 не начат.
