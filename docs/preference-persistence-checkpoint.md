# Сохранение настройки после обновления — 07.10.2026

Владелец подтвердил: мягкие подсказки выключились при первом переходе 1.22 → 1.23. Причина — смена источника настройки: 1.22 хранила `serbotalk.soft-assistance.<user_id>` в localStorage, а миграция 1.23 создала `users.assistance_enabled` с DEFAULT false. Старый локальный выбор автоматически не переносился. Это потеря выбора при переходе на серверное хранение, а не подтверждённый повторный сброс уже сохранённой настройки 1.23.

- [x] Production Supabase: Alembic `f42b8c012d33`; поле `users.assistance_enabled` существует, boolean / NOT NULL / DEFAULT false. Схема проверена read-only, пользовательские настройки не менялись.
- [x] PATCH сохраняет настройку с commit в БД текущего аккаунта; GET preferences и auth/me читают её из БД. Вход/обновление профиля не назначают default существующему пользователю. Версия клиента не участвует в ключе хранения или записи настройки.
- [x] Новая регрессия для true и false: запись через реальный API/auth sync, закрытие TestClient и engine, открытие новой connection к файловой БД, повторный Alembic head/seed, новый вход с обновлёнными profile metadata и другим client User-Agent. Оба GET и отдельная DB session возвращают сохранённый выбор.
- [x] UI регрессия для true и false: запись, unmount, новый экземпляр клиента, противоположный legacy localStorage/default; серверный выбор восстановлен, PATCH на запуске отсутствует. 7 frontend preference tests и 8 backend preferences/migration tests прошли; lint/typecheck/web build прошли.
- [ ] Физическая приёмка перезапуска Android после сохранения в 1.23.

Повторное включение в 1.23 сохраняет выбор в профиле; обновления клиента после этого не требуют повторного включения. Старый локальный флаг не должен автоматически перезаписывать явное отключение в общем профиле: в данных 1.23 нет признака, позволяющего отличить default false от намеренного false. Автоматическое восстановление старого true по этому флагу не добавлялось.

Runtime, миграции и APK в этой проверке не менялись; production-перевыпуск не требуется. Добавлены regression tests и документация. Алфавит сербского языка пока хранится локально по user_id без номера версии; проверка серверного хранения относится к мягким подсказкам. Не утверждаем, что все настройки уже перенесены в БД.
