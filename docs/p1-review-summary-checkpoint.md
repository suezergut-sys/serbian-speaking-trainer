# P1.3 — компактный счётчик повторения, 30.09.2026

Экран тем теперь запрашивает количество доступных фраз вместо их полной истории. Старый список сохранён для выпущенных Android-клиентов; получение названий тем больше не создаёт запрос на каждую фразу. Полный P1 и ручная приёмка остаются открытыми.

## Изменение

- Новый `GET /api/review-phrases/summary` возвращает `{"phrase_count": число}`. Перед подсчётом выполняется прежняя активация просроченных карточек; число соответствует длине старого списка. Фильтр пользователя и правила интервалов сохранены.
- Старый `GET /api/review-phrases` возвращает прежние поля и порядок. `OUTER JOIN` получает только название общей или собственной темы; чужое название остаётся `null`, сама принадлежащая пользователю фраза сохраняется в выдаче.
- Web хранит число для карточки повторения и обновляет его после оценки, добавления фразы и возврата страницы. Добавление существующей фразы не увеличивает число искусственно. Поздний ответ не восстанавливает уже опустевшую очередь или данные другого аккаунта.
- Сводка не задерживает первую фразу или показ оценки. Дополнительные фоновые запросы не заменяют успешное сохранение ошибкой обновления счётчика.
- Схема БД и индексы не менялись. SQLite EXPLAIN использует существующий индекс статуса и PK темы; доказанной необходимости нового индекса на этом срезе нет.

Это прогретый локальный запрос без сетевого транспорта и настоящего OAuth/AI. Просроченные карточки активируются во время прогрева. Результат не является измерением холодного Vercel-запуска или скорости физического телефона. Детерминированные сокращения SQL, размера ответа и загрузки моделей проверяются отдельно от длительностей.

## Проверки

- Backend + scripts: 145 passed, 8 skipped без PostgreSQL DSN (121 backend и 24 вспомогательных теста). Отдельный запуск SQLite/PostgreSQL счётчика: 2/2 passed, без пропусков. Integration test покрывает 120 активных карточек, активацию просроченных, будущие сроки, видимость тем, равенство счётчика списку и постоянное число SQL.
- Frontend: 63/63 unit/component, 3/3 mocked E2E, TypeScript, ESLint и production build прошли. Существующее предупреждение о размере chunk сохраняется.
- Независимое ревью GPT-6.1 Sol / medium приняло backend, frontend и benchmark без подтверждённых замечаний.
- Настоящий локальный API: 2/2 web E2E прошли. Полный цикл установленного Android lab 1.15 прошёл: это совместимость прежнего клиента с новым backend, а не проверка нового клиентского счётчика. PostgreSQL 17.11 подтвердил активацию просроченных фраз, совпадение списка/счётчика и изоляцию пользователей.
