# 22.10.2026 — «Поделиться приложением» и черновики Google Play

## Выполнено локально

- [x] В общие настройки web/Android-layout добавлена секция RU/EN: «Поделиться», «Скопировать ссылку», доступное для выделения readonly-поле URL. Состояния ожидания, ошибки и копирования локализованы; палитра, шрифт, focus и disabled соответствуют общим CSS-переменным.
- [x] Выбрана публичная ссылка `https://serbotalk.app/`, без ID пользователя, токенов, текущего URL или параметров закрытого теста. 22.10 HTTP GET подтвердил 200 и наличие SerboTalk/`/app` в HTML. Лендинг даёт вход в web; обещание установки Android по этой ссылке не добавлено. Google Play badge в текущем `LandingPage.tsx` ещё помечен «Ссылка появится после публикации».
- [x] Для native предусмотрен официальный `@capacitor/share` **8.0.3**, совместимый с текущим Capacitor 8. На web используется `navigator.share`, вызываемый непосредственно из клика до первого await. При отсутствии механизма отправки — clipboard; явная кнопка Copy доступна всегда. Если clipboard недоступен/запрещён, URL остаётся для ручного копирования. При ошибке share автоматическое копирование не выполняется; пользователь выбирает дальнейшее действие.
- [x] Отмена browser AbortError и native `Share canceled` не показывает ошибку и не меняет буфер обмена. Android-строка отмены проверена по коду установленного официального пакета. Повторный клик во время операции блокируется; успешное закрытие меню не выдаётся за доказательство доставки сообщения.
- [x] В dependency/lockfile добавлен только share-плагин, остальные разрешённые версии сохранены. `pnpm install --frozen-lockfile` прошёл. Android sync/build и версии не менялись; plugin registration будет создана только при отдельно разрешённом Android-релизе.
- [x] Подготовлены [RU/EN описания](google-play-descriptions-2026-10-22.md) для согласования. По уточнению владельца 22.10.2026 все материалы ориентированы на 1.38 или новее; 1.30 используется только как история закрытого трека.
